# Читацький щоденник

CRUD-вебзастосунок з реляційною базою даних для ведення особистого читацького щоденника та взаємодії в читацьких клубах.

## Опис проєкту

Проєкт створено як розширення курсової роботи для зручного обліку прочитаної літератури та спільного читання.

### Основні можливості:
- **Авторизація та профілі:** реєстрація й безпечний вхід користувачів.
- **Облік книг (CRUD):** додавання, редагування, перегляд та видалення записів про прочитані книги.
- **Фільтрація та пошук:** швидке сортування книг за авторами та жанрами.
- **Оцінки та нотатки:** можливість виставляти оцінки книгам і вести особисті враження чи цитати.
- **Читацькі клуби:** створення спільних спільнот, запрошення користувачів, формування списків запланованих для читання книг та голосування за наступну книгу клубу.
