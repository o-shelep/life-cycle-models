# SRS v1.0 — Модуль читацьких клубів

## 1. Вступ
Розширення функціоналу читацького щоденника: додавання групової взаємодії,
спільних планів читання та обговорень.

## 2. Актори
- Зареєстрований читач
- Власник / Модератор читацького клубу
- Гість (неавторизований)

## 3. Функціональні вимоги
- FR-1 ... FR-5 (перелік зі списку вище)

## 4. Нефункціональні вимоги
- NFR-1 ... NFR-5 (перелік зі списку вище)
